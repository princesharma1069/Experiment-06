## Title: 
Study of conditional statements in python
## Theory:
In Python, if-elif-else is a conditional control structure used to direct program execution based on logical conditions. 
The if statement evaluates an initial condition; if it is true, its block executes. If it is false, Python evaluates subsequent elif conditions in order. 
The optional else block executes only when all preceding conditions are false. 
Evaluation proceeds sequentially, and only the first true condition’s block is executed.
## Algorithm:

3)If a > 0, print "Number is positive"
4)Else if a < 0, print "Number is negative"
5)Else, print "Number is zero"
6)Stop
